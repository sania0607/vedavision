# Quick Start Guide - VedaVision Yoga Coach

## Fast Installation (Windows)

Open PowerShell in this directory and run these commands:

```powershell
# Install dependencies
pip install -r requirements.txt

# Run the yoga coach
python yoga_coach.py
```

## First Time Setup

1. When the application starts, your webcam will activate
2. Position yourself 6-8 feet from the camera
3. Make sure your entire body is visible
4. Press a number (1-5) to select a yoga pose
5. Follow the on-screen feedback!

## Keyboard Controls

| Key | Action |
|-----|--------|
| `1` | Tree Pose |
| `2` | Warrior II Pose |
| `3` | Triangle Pose |
| `4` | Downward Dog |
| `5` | Mountain Pose |
| `Q` | Quit application |

## Quick Tips

✅ **DO:**
- Wear fitted, contrasting clothing
- Practice in good lighting
- Keep your full body in frame
- Stand still while the AI analyzes your pose

❌ **DON'T:**
- Wear baggy clothes that hide your body shape
- Practice in dim lighting
- Move too quickly between poses
- Stand too close or too far from the camera
